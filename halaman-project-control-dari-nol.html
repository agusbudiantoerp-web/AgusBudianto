CUT-OFF: BULAN 5
Planned (PV) Actual (EV)
BAB PALING PENTING

Earned Value Management, dalam enam variabel inti.

Seluruh analisis kinerja proyek modern bertumpu pada tiga angka dasar ini — dari situ, indeks dan proyeksi biaya akhir proyek dapat dihitung secara objektif. Buka Bab 4 di bawah untuk teori dan studi kasus numerik lengkapnya.

PLANNED VALUE
PV = %Rencana × BAC
EARNED VALUE
EV = %Aktual × BAC
SCHEDULE INDEX
SPI = EV / PV
COST INDEX
CPI = EV / AC
ESTIMATE AT COMPLETION
EAC = BAC / CPI
VARIANCE AT COMPLETION
VAC = BAC − EAC

Urutan belajar dari nol hingga mahir.

Buka setiap bab, lalu pilih sub-bab untuk membaca teori singkat, studi kasus, dan pembahasannya. Setiap bab juga memuat daftar referensi lanjutan di bagian bawah.

UNTUK SIAPA

Dirancang untuk peran yang menjalankan kendali proyek sehari-hari.

Planner / Scheduler

Menguasai WBS, logika ketergantungan, critical path, dan resource leveling untuk membangun jadwal yang realistis dan dapat dieksekusi.

Cost / Project Control Engineer

Menghitung EVM (SPI, CPI, EAC) secara akurat, membangun dashboard, dan menyampaikan status proyek berbasis data ke manajemen.

Project Manager

Memahami bahasa data project control untuk mengambil keputusan cepat: kapan harus eskalasi, kapan cukup memantau.
