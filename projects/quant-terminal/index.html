Sumber data riil — Zapi (zapi.ink)  

      Saham tambahan  
Cara memakai: (1) buat file zapi_key.txt di folder aplikasi berisi API key Anda, lalu restart server (key hanya dibaca server dan tidak pernah dikirim ke browser — jangan menempelkannya ke chat/forum); (2) Uji koneksi; (3) Unduh riwayat sekali untuk mengganti data simulasi dengan data harian riil (halaman memuat ulang sendiri); (4) Perbarui harian tiap hari bursa (hanya 1 request/hari). Paket gratis Zapi 600 request/bulan: hitungan di sini hanya perkiraan lokal, hitungan resmi ada di dashboard Zapi. Zapi adalah agregator pihak ketiga yang mengambil data dari sumber lain (bukan feed resmi bursa), harga tidak disesuaikan aksi korporasi (split/dividen), dan syarat penggunaannya perlu Anda baca sendiri. Bukan saran investasi.

Baca dengan hati-hati: order book bersifat anonim, jadi alat ini tidak bisa mengetahui siapa yang bertransaksi. Dinding di buku bisa dibatalkan kapan saja, dan hasilnya heuristik jangka sangat pendek yang tidak menjamin arah harga. Data riil memerlukan file feed dari sumber Anda sendiri (lihat orderflow/README.txt); tanpa itu panel memakai SIMULASI. Bukan saran investasi.

Backtest universe — satu strategi atas semua saham       memakai strategi & parameter di bar atas

Walk-forward — optimasi di training, uji di periode berikutnya (aset terpilih)   Training Test bar         parameter cepat/lambat di bar atas diabaikan; dioptimasi otomatis per fold

Efisiensi WF = Sharpe OOS ÷ rata-rata Sharpe in-sample. Mendekati 1 = hasil bertahan di luar sampel; di bawah ~0,5 atau negatif = indikasi overfitting. Garis putus-putus = batas fold.

Portofolio satu rekening — modal bersama, batas jumlah posisi   Maks posisi Maks/sektor Prioritas       long-only; tiap posisi = ekuitas ÷ maks posisi; strategi & parameter dari bar atas

Walk-forward portofolio — parameter & maks posisi (5/10/20) dioptimasi per fold     memakai jendela Training/Test dari panel walk-forward di atas

Walk-forward multi-saham — stabilitas parameter       memakai jendela & opsi stop dari panel walk-forward; sekitar 5–60 detik

Frekuensi pemilihan parameter di semua fold & saham
Parameter stabil = pilihan sering sama antar fold dan antar saham (pangsa kombinasi terpopuler tinggi, pergantian antar-fold rendah) dan Sharpe OOS mendekati IS. Heatmap yang tersebar rata menandakan optimasi hanya mengejar noise.

Uji ketahanan — Monte Carlo & perturbasi parameter   Objek Simulasi     memakai strategi & parameter di bar atas (portofolio: K, prioritas, LQ45 dari panel portofolio)

① Max drawdown — urutan trade diacak
② Return akhir — bootstrap trade (dengan pengembalian)
③ Return akhir — 20% trade dibuang acak
④ Sharpe — parameter diperturbasi ±25% (stop ±30%)
Garis kuning = hasil asli. ①–③ bekerja pada level trade (drawdown intra-trade tidak terhitung); mengacak urutan tidak mengubah return akhir, hanya jalurnya. Persentil ke-5 return bootstrap di bawah 0, atau hanya sebagian kecil parameter tetangga yang profit, menandakan edge rapuh. Hasil dengan trade sedikit (< ~30) kurang meyakinkan secara statistik.

Uji stres — skenario historis & guncangan sintetis   Objek Jendela kustom –     memakai strategi & parameter di bar atas

Jendela historis memakai tanggal perkiraan di universe.py (STRESS_WINDOWS); yang di luar rentang data ditandai. Guncangan sintetis dijatuhkan saat eksposur strategi tertinggi (garis putus-putus), harga turun permanen dan sinyal dihitung ulang; di IDX, guncangan lebih besar dari batas ARB membuat penjualan tertunda. Selisih bisa positif untuk skenario volatilitas karena strategi bereaksi berbeda.
